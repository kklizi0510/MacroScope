# MacroScope

## 中文

项目集合，按目录归类。当前项目：[MacroScope](MacroScope/)——中美日宏观经济可视化、描述统计与双序列相关性分析，支持中文、日文和英文。

Streamlit 部署：入口 `MacroScope/app.py`，Python 3.12；在 Secrets 配置自己的 `FRED_API_KEY`。本地运行先进入 `MacroScope` 目录。项目说明与 MIT 许可证见该目录。

## 日本語

プロジェクトをディレクトリ別に整理したリポジトリです。[MacroScope](MacroScope/) は日米中のマクロ経済可視化、記述統計、2系列相関分析を提供し、日本語・中国語・英語に対応します。

Streamlit の入口は `MacroScope/app.py`、Python は 3.12 です。Secrets にご自身の `FRED_API_KEY` を設定してください。ローカル実行は `MacroScope` ディレクトリ内で行います。詳細と MIT ライセンスは同ディレクトリにあります。

## English

A collection of projects organized by directory. [MacroScope](MacroScope/) provides macroeconomic visualization for China, the US and Japan, descriptive statistics and two-series correlation analysis, with English, Chinese and Japanese interfaces.

For Streamlit, use `MacroScope/app.py` as the entrypoint and Python 3.12. Set your own `FRED_API_KEY` in Secrets. Run local commands from the `MacroScope` directory; its README and MIT license contain project details.
