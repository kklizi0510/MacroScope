# MacroScope

A collection of projects organized by directory. [MacroScope](MacroScope/) provides macroeconomic visualization for China, the US and Japan, descriptive statistics and two-series correlation analysis, with English, Chinese and Japanese interfaces.

For Streamlit, use `MacroScope/app.py` as the entrypoint and Python 3.12. Set your own `FRED_API_KEY` in Secrets. Run local commands from the `MacroScope` directory; its README and MIT license contain project details.
